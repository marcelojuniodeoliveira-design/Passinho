# Passinho a Passo

App de brincadeiras para alfabetização, fala, números, raciocínio e histórias de dormir, feito para uma criança específica.
Funciona sem internet depois de instalado (PWA).

- Instalar no Android: abrir o endereço do GitHub Pages no Chrome → ⋮ → Instalar app.
- Os arquivos são gerados por `build_android.py` a partir de `index.html` do projeto.
